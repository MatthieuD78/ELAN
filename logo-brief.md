# ÉLAN — Brief créatif logo (v2, méthode d'agence)

## Stage 1 — Brief
- **Marque** : ÉLAN — développement personnel
- **Secteur** : développement personnel / coaching / bien-être orientation pro
- **Tagline** : « La transformation, accompagnée »
- **Public** : personnes qui veulent changer, budgets variés ; ton accessible,
  chaleureux, jamais élitiste.
- **Valeurs** (3) : **mouvement / élan** (impulsion), **accessibilité**,
  **accompagnement**.
- **Différenciateur** : « le couple » ebook + app IA d'accompagnement — une vraie
  transformation suivie, accessible à toutes les bourses.
- **Usages** : favicon, app icon, web/landing, réseaux sociaux, print (KDP).
  → impose un **combo** (marque + mot) + une **icône simple** + un **favicon**.
- **Non-négociables** : palette tokens slate `#0f172a` / ambre `#FBBF24` /
  émeraude `#10B981` (réel), Playfair Display (titres), Inter/Lato (texte).
- **Interdits (clichés du secteur à éviter)** : personnage bras levés, lotus,
  soleil levant, main, « l'idée mot = l'idée dessin » (bois de wapiti littéral),
  swoosh générique, poids plume new-age.

## Stage 2 — Direction
Références par le sentiment visé : wordmark/premium (type Playfair) + un geste
géométrique de **montée / impulsion** qui ne peut se lire ni main ni bois ni
boussole. Direction retenue **monochrome-first**, geste fort, contrefomme qui
travaille, robuste à 16–600 px.

**Concepts à explorer (croquis, tous en noir & blanc) :**
- **A** *Élan accent* — lettermark/abstract : un « É » géométrique dont l'accent
  devient une flèche montante. Typographie/premium, singulier.
- **B** *Impulsion* — abstract : geste ascendant monobloc qui jaillit (ni main,
  ni bois), forward-élan.
- **C** *Parcours* — picto abstrait : échelle de pas montante (progression,
  accompagnement) pointant vers le haut.
- **D** *Contre-forme* — la forme négative révèle une flèche/tick montant
  (transformation = accomplissement). L'espace vide travaille.
- **E** *Accélération* — motif : traits ascendants parallèles (mouvement/départ).

Règle : dessiner en **aplat noir sur blanc**, pas de couleur. Ne garder après
critique que les concepts qui passent : mémorable, singulier, pas un cliché,
négatif net, survit en NAV & blanc et à 16px.
